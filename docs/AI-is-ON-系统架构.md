## 二、各模块详解

### 模块 1：感知层（Perception）

**职责：** 持续采集用户世界中的信号，不依赖用户主动输入。

```
┌─────────────────────────────────────────────┐
│                感知层                         │
│                                             │
│  ┌─────────────┐  ┌─────────────┐          │
│  │ 被动采集器  │  │ 主动探测器  │          │
│  │ Passive     │  │ Active      │          │
│  └──────┬──────┘  └──────┬──────┘          │
│         │                │                  │
│  ┌──────┴──────┐  ┌──────┴──────┐          │
│  │ • 邮件流    │  │ • 定时拉取  │          │
│  │ • 消息流    │  │ • 状态轮询  │          │
│  │ • 日历变更  │  │ • 异常检测  │          │
│  │ • 文件变更  │  │ • 趋势分析  │          │
│  │ • 位置信号  │  │             │          │
│  └──────┬──────┘  └──────┬──────┘          │
│         └────────┬───────┘                  │
│                  ▼                          │
│         ┌──────────────┐                    │
│         │ 信号标准化器 │                    │
│         │ Signal       │                    │
│         │ Normalizer   │                    │
│         └──────┬───────┘                    │
│                ▼                            │
│         输出：统一信号流                     │
│         {source, type, content, timestamp}  │
└─────────────────────────────────────────────┘
```

**关键设计：**
- 采集器永远在跑，不需要用户触发
- 信号标准化后统一进入系统，不分来源
- 用户不说话时，系统也在感知

- 决策器是"AI is ON"的核心——AI 自己决定什么时候做什么

### 模块 4：信任层（Trust / Boundary）

**职责：** 管理 AI 的自主权边界，随时间动态学习。

```

│                信任层                         │
│                                             │
│  ┌─────────────────────────────────────┐    │
│  │       Boundary Store                │    │
│  │  ┌──────────┐  ┌──────────┐        │    │
│  │  │ Personal │  │Enterprise│        │    │
│  │  │ 个人策略 │  │ 企业策略 │        │    │
│  │  └──────────┘  └──────────┘        │    │
│  └──────────────────┬──────────────────┘    │
│                     │                       │
│  ┌──────────────────┼──────────────────┐    │
│  │       信任引擎 Trust Engine          │    │
│  │                                      │    │
│  │  ┌──────────┐  ┌──────────────┐     │    │
│  │  │ 权限检查 │  │ 信任度评估   │     │    │
│  │  │(静态规则)│  │(动态学习)    │     │    │
│  │  └──────────┘  └──────────────┘     │    │
│  │                                      │    │
│  │  ┌──────────┐  ┌──────────────┐     │    │
│  │  │ 审计日志 │  │ 反馈学习器   │     │    │
│  │  │(可追溯)  │  │(卡片→规则)   │     │    │

│  L0: 只能建议（新用户默认）                  │
```

- 每次用户"选"卡片上的"以后自动"→ 信任度+1
- 信任是分领域、分操作类型的，不是全局一个值

## 三、模块间的数据流

### 流 1：用户说了一句话

```
用户输入 → 感知层(标准化) → 推理层(意图+计划)
  → 信任层(能不能自动做) → 行动层(执行)
  → 记忆层(结果回流) → 呈现层(推卡片/回复)
```

### 流 2：环境信号触发（用户没说话）

```
环境信号(邮件/日历变更) → 感知层(标准化)
  → 推理层(要不要处理) → 记忆层(查相关上下文)
  → 信任层(能不能自动做)
  → 行动层(执行) 或 呈现层(推卡片通知用户)
```

### 流 3：后台持续运行

```
Caring Agent(常驻) → 持续读取记忆层 + 感知层
  → 分析用户状态 → 写便签到记忆层
  → 设闹钟触发推理层 → 呈现层(合适时间推卡片)
```

### 流 4：信任学习闭环

```
呈现层(推卡片) → 用户选择"以后自动"
  → 信任层(更新规则) → 下次同类场景
  → 推理层直接执行 → 呈现层(不再推卡片)
```

## 四、"AI is ON" vs 传统架构的核心区别

```
传统架构：  用户 → 触发 → AI 处理 → 返回结果 → 结束
AI is ON：  环境信号 ──┐
            用户输入 ──┼→ 感知 → 推理 → 行动 → 呈现
            定时任务 ──┘    ↑        ↑
                         记忆      信任
                       (一直在)  (一直在学)
```
